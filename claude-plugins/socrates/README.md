# socrates

**소크라테스식 질답**으로 앵커를 잡고, 질문과 답을 반복하며 스스로 답에 도달하게 만드는 플러그인이에요.

## 커맨드

- `/scrt ask {공부하고 싶은것}` — `socratic-tutor` 스킬로 질답을 시작해요.
- `/scrt record` — `socratic-record` 스킬로 지금까지의 질답을 복습용 기록 문서로 정리해요.

커맨드 없이 "소크라테스식으로 알려줘", "이 대화 정리해줘" 같은 자연어 요청으로도 각 스킬이 트리거돼요.

## 스킬 두 개

### socratic-tutor

질답 진행자예요. 사용자의 최초 질문을 앵커로 고정하고, 답을 바로 주는 대신 질문을 이어 붙여 스스로 오류를 발견하고 고쳐 나가게 해요. 곁길로 새는 논점은 답하지 않고 보류해뒀다가, 앵커에 도달한 뒤 새 질문으로 돌려줘요.

트리거 — "소크라테스식으로 알려줘", "답 말고 질문으로", "스스로 깨닫게 해줘" 같은 요청.

### socratic-record

socratic-tutor로 진행한 질답(또는 시행착오가 있던 다른 대화)을 사용자 본인의 복습용 기록 문서로 정리해요. 요약이 아니라 사용자의 답변을 원문 그대로 보존하고, 각 답이 나온 사고 경로를 복원하는 게 핵심이에요.

트리거 — "이 대화 정리해줘", "학습 기록으로 남겨줘", "복습용으로 저장해줘" 같은 요청.

## 설치

이 플러그인은 dotfiles 리포의 로컬 마켓플레이스 `dotfiles`(`~/.config/claude-plugins`)에 속해요.

```sh
claude plugin marketplace add ~/.config/claude-plugins   # 이미 등록돼 있으면 생략
claude plugin install socrates@dotfiles
```
