# sdd:brief-nondev — 직원 누구나 읽는 기획 문서

요구사항 문서를 받아, 코드를 읽지 않는 직원도 끝까지 읽고 의견을 낼 수 있는 사본을 쓴다. 모양은 요구사항 문서 그대로이고, 개발 언어만 걷어 낸다. 코드는 바꾸지 않는다.

먼저 `${CLAUDE_PLUGIN_ROOT}/references/brief-format.md` 를 읽는다. 입력과 출력, 「변환 원칙」, 「마커 제거」, 「개발 언어 순화」, 「답 반영」은 그 문서를 따른다.

- `sdd:draft`: 이 스킬의 입력(requirements.md)을 쓴다
- `sdd:brief-dev`: 같은 입력으로 마커만 지운 `brief-dev.md` 를 쓴다

## 입력 찾기

- 설명에 경로가 있으면 그 `requirements.md`. 폴더면 그 안의 `requirements.md`
- 없으면 `spec-format.md` 「저장 위치」의 「폴더 고르기」로 폴더를 고른다. 폴더가 하나도 없거나 고른 폴더에 `requirements.md` 가 없으면 쓰지 않고 "`/sdd:draft` 를 먼저 실행하세요" 한 줄을 남긴다
- 입력에 `(작성 중)` 이 남아 있으면 쓰지 않고, 그 절 이름을 알려 준다
- 설명에 "artifact", "아티팩트" 가 있으면 「공유 문서 경로」, 없으면 마크다운으로 쓴다

## 쓰는 순서

- 입력을 끝까지 읽는다. 앞부분만 보고 쓰지 않는다
- 채팅에 "{입력 폴더}/brief-nondev.md 에 씁니다" 한 줄을 남긴다
- 「마커 제거」와 「개발 언어 순화」를 적용해 Write 로 한 번에 쓴다
- 검증한다. 하나라도 걸리면 고치고 다시 검증한다
    - 마커: `grep -nE '@(결정|해석|초안|미정|사실|가정|확정)' brief-nondev.md` 결과가 없다
    - 표기 열: `grep -n '표기 |' brief-nondev.md` 결과가 없다
    - EARS: `grep -nE 'THE System|SHALL|WHEN |WHILE |IF .*THEN' brief-nondev.md` 결과가 없다
    - 코드: ``` 블록 밖에서 `` grep -n '`' `` 결과가 없다
    - 구조: `grep '^#' requirements.md` 와 `grep '^#' brief-nondev.md` 가 같다
    - 번호: `grep -c '^[0-9]\+\. '` 가 입력과 같다
- 「쉬운 말 점검」을 한다

## 쉬운 말 점검

- `Agent` 로 하위 에이전트 하나를 띄운다. 넘기는 것은 문서 경로와 아래 역할뿐이다. 이 대화의 맥락은 넘기지 않는다. 맥락을 알면 모르는 말도 알아듣기 때문이다
    - 역할: "당신은 코드를 읽지 않는 운영 담당 직원이다. 이 문서를 처음부터 끝까지 읽고, 뜻을 모르겠거나 두 가지로 읽히는 말을 문장과 함께 목록으로 돌려 달라. 문서 안 「도메인 언어」에 뜻이 적힌 용어와 POS·키오스크·정산 같은 업무 용어는 올리지 말라. 뜻이 어디에도 없는 말만 올려라. 고치지는 말라."
    - 공유 문서면 본문을 마크다운으로 뽑아 임시 파일에 쓰고 그 경로를 넘긴다
- 돌려받은 말을 나눈다
    - 개발 언어 → 「개발 언어 순화」로 고친다
    - 업무 용어인데 뜻이 정의되지 않은 말 → 고치지 않고 끝맺음에 "도메인 언어 후보" 로 적는다
- 고친 문장이 5개 이상이면 한 번 더 점검한다. 점검은 최대 두 번이다

## 공유 문서 경로

입력이 공유 문서 링크이거나 설명에 아티팩트 요청이 있을 때만 쓴다.

- 입력 문서를 읽는 도구와 새 문서를 만드는 도구는 `sdd:draft` 「공유 문서 경로」를 따른다
- 내용은 마크다운 경로와 같다. 공유 문서는 표를 그려 주므로 표를 그대로 둔다
- 다 만들면 문서 링크를 끝맺음 둘째 줄에 둔다

## 끝맺음

- 첫 줄: 다음 행동 하나
    - 열린 결정이 있으면: 다음에 답할 결정 하나와 추천안. 답은 `requirements.md` 에 반영된다고 붙인다
    - 없으면: 문서를 직원에게 공유하는 행동 한 줄
- 둘째 줄: 문서 경로(클릭 가능한 `path`) 또는 링크
- 무엇을 지우거나 바꿨는지 불릿 5개 이하. 문서 내용을 채팅에 다시 늘어놓지 않는다
- 쉬운 말 점검에서 고친 문장 수와, 도메인 언어 후보가 있으면 그 말

## 하지 않는 것

- 코드를 바꾸지 않는다
- 조사하지 않는다. 결정·절·예시·그림·이야기를 더하지 않는다
- 도메인 언어와 업무 용어, 마스터 답 원문을 바꾸지 않는다
- 인수 조건 한 줄을 여러 줄로 나누지 않는다
- 마스터 답을 brief-nondev.md 에 반영하지 않는다. `requirements.md` 에 반영하고 다시 만든다
