# 기록 규칙 (aol 플러그인)

마스터의 프롬프트 원문은 훅이 알아서 남긴다. LLM 이 할 일은 하나뿐이다.

마스터가 LLM 의 직전 행동을 고치거나 되돌리게 했으면, 그 응답의 마지막 줄에 한 줄을 붙인다.

`[aol] corr="<무엇을 잘못했나 한 문장>" rule=<어긴 규칙의 절 제목, 없으면 none>`

- `corr` 값 안에는 큰따옴표를 쓰지 않는다. `rule` 값의 공백은 `-` 로 바꾼다.
- 정정이 아닌 턴에는 아무것도 붙이지 않는다. **마커가 없는 것이 정상이다.**
- 예: `[aol] corr="테스트를 돌리지 않고 커밋했다" rule=커밋`

정정 사실만 이렇게 남기는 이유는, 무엇을 왜 틀렸는지가 프롬프트 원문에 안 남기 때문이다. 요청이 무엇이었는지는 원문이 말해주지만, LLM 이 그걸 어떻게 어긋나게 읽었는지는 그 자리의 LLM 만 안다.

의도·대상·크기 라벨은 붙이지 않는다. 미리 정한 이름표에 맞추는 순간, 나중에 그 프롬프트를 다르게 묶어볼 자유가 사라진다.
