# roguelike — 죽더라도 지식은 남기고, 새 세션이 이어받는다

로그라이크에서 캐릭터는 죽지만 맵과 아이템에 대한 지식은 다음 판으로 넘어가요. 세션도 같아요. 컨텍스트가 차면 이 세션은 끝나지만, 인수인계 문서가 남으면 다음 세션이 같은 지점에서 다시 시작해요.

이 skill 이 하는 일은 두 가지예요.

- 남은 작업을 **재시작 가능한 수준**의 문서 하나로 떨어뜨려요.
- 그 문서를 물린 새 세션을 백그라운드로 띄워요. 결과는 기다리지 않아요.

## 판정 기준

문서의 기준은 하나예요: **아무 컨텍스트 없는 새 세션이 이 문서만 보고 질문 없이 다음 커밋을 만들 수 있는가.** 이 기준에 못 미치면 아직 문서가 아니에요.

다음 세션에 존재하는 것은 이 문서뿐이에요. 지금 세션이 읽은 파일, 돌려본 명령, 버린 대안, 마스터가 말한 제약은 문서에 적히지 않으면 전부 사라져요. "그건 코드를 보면 알겠지" 는 다음 세션이 같은 조사를 처음부터 반복한다는 뜻이에요.

## 절차

### 남은 작업의 경계를 긋는다

먼저 세 가지를 가른 뒤에 쓰기 시작해요.

- 이미 끝난 것 — 커밋됐거나 파일에 반영된 것.
- 남은 것 — TODO 가 될 것.
- 확정 못 한 것 — 다음 세션이 마스터에게 물어야 할 것. 문서에 "확인 필요" 로 남겨요.

완수조건이 정해져 있지 않으면 여기서 정해요. 완수조건 없는 인수인계는 다음 세션이 어디까지 하고 멈출지 모른다는 뜻이에요.

### 문서를 쓴다

저장 위치는 작업 중인 워크트리(git 리포가 아니면 작업 디렉터리) 루트의 `.claude/roguelike/{YYYYMMDD-HHmm}-{slug}.md` 예요. `{slug}` 는 영어 kebab-case 로 짧게. 새 세션이 이 디렉터리에서 뜨니 경로가 안 흔들려요.

이 문서는 작업 산출물이 아니라 세션 간 메모라서 커밋하지 않아요. 리포가 추적하지 않게 하려면 마스터에게 `.gitignore` 에 `.claude/roguelike/` 추가를 제안해요. 다만 새 세션을 다른 머신이나 다른 워크트리에서 띄울 계획이면 커밋해야 넘어가니, 그때는 마스터에게 확인받고 커밋해요.

형식은 아래 헤딩을 그대로 써요. 해당 사항이 없는 절은 지우지 말고 "없음" 이라고 적어요 — 절이 비어 있는 것과 절이 사라진 것은 다음 세션에게 다른 뜻이에요.

```markdown
## 개요

{무엇을, 왜 하고 있는지 한 문단. 마스터가 말한 제약과 요구는 원문 표현 그대로 인용}

## 완수조건

- {관찰 가능한 조건. "이게 되면 끝"}
- {테스트로 확인되는 것이면 그 테스트 이름}

## 조사 결과

### 현재 동작

{지금 코드가 하는 일. 근거는 `path/to/file.ts:42` 형태로}

### 영향 범위 (전수)

- `path/a.ts:10` — {왜 관련되는지}
- `path/b.ts:88` — ...

### 기존 패턴

{같은 종류의 일을 이 코드베이스가 이미 처리하는 방식과 그 위치}

### 확인한 불변식

- {날짜 윈도우면 구체 날짜로 포함/미포함, 수치면 이상/이하/초과/미만, 화폐·정산이면 소숫점 정밀도}

### 실측한 것

- {직접 돌려본 명령과 그 결과. 다음 세션이 다시 돌리지 않아도 되게}

### 확인 필요

- {확정 못 한 것 + 어떻게 확인할지. 없으면 "없음"}

## 배포 방식

{바뀐 것이 실제 환경에 어떻게 닿는지. 빌드·동기화 스크립트·재시작·마이그레이션 순서. 되돌리는 방법도 함께}

## TODO

- [ ] {단계 1 — 파일·함수 수준으로}
- [ ] {단계 2}
- [x] {이미 끝낸 것도 남겨요. 다음 세션이 중복 작업을 피하는 근거예요}

## 테스트 방법

{검증 시나리오와 실행할 명령. 명령은 복사해서 바로 돌릴 수 있게 그대로}

## 범위 밖 발견

- {이번 작업과 무관한데 눈에 띈 문제. 고치지 말고 적기만. 없으면 "없음"}

## 세션

- 직전 세션 ID: `{uuid}`
- 근거 질문: `/qa {uuid}, {질문}` 으로 직전 세션에 물을 수 있다
- 이어서 만든 문서면 앞선 문서 경로도 함께 적는다

## 요청 원문

> {마스터가 말한 문장 그대로 인용}
```

빠지기 쉬운데 다음 세션이 다시 만들기 가장 어려운 것들이에요. 쓰기 전에 확인해요.

- 내린 결정과 **버린 대안**, 그리고 버린 이유. 이유가 없으면 다음 세션이 같은 갈림길에서 같은 고민을 반복해요.
- 파일 경로, 라인 번호, 함수명, 외부 문서 URL.
- 이미 돌려본 명령과 그 출력. 특히 실패한 시도.
- 마스터의 제약은 요약하지 말고 원문 표현으로.

### 현재 모델을 알아낸다

새 세션은 지금과 같은 모델로 띄워요. 모델이 바뀌면 판단 기준이 바뀌니까요.

- 1순위 — 시스템 프롬프트에 적힌 모델 ID (예: `claude-opus-5[1m]`). 대괄호가 있으면 셸에서 glob 으로 먹히니 반드시 작은따옴표로 감싸요.
- 2순위 — 트랜스크립트에서 실제 응답 모델을 읽어요. 별칭으로 띄운 `--model` 값은 실제 모델의 근거가 못 돼요.

  ```bash
  sid={현재 session_id}
  grep -h '"type":"assistant"' ~/.claude/projects/*/"${sid}".jsonl \
    | jq -r '.message.model // empty' | grep -v synthetic | tail -1
  ```

- 둘 다 못 구하면 `--model` 을 아예 빼요. 설정의 기본 모델로 떠요. 틀린 모델을 찍어 넘기는 것보다 나아요.

### 새 세션을 백그라운드로 띄운다

```bash
(cd {워크트리 절대경로} && claude --bg --model '{모델 ID}' \
  --name "이어작업: {한글 짧은 제목}" \
  "@{문서 절대경로} 이 인수인계 문서를 읽고 TODO 의 첫 미완 항목부터 이어서 작업해라. 문서의 완수조건이 기준이다. {추가 지시}")
```

실측으로 확인한 것들이에요 (Claude Code 2.1.270).

- **`--print` 와 `--bg` 는 함께 못 써요.** `--print` 는 인터랙티브 세션을 띄우지 않아서 `claude agents` 가 붙을 수 없는 잡이 되고, CLI 가 거부해요. 프롬프트는 positional 로 줘요.
- `@` 뒤 파일 참조는 **절대경로**로 줘요. 새 세션이 그 파일을 실제로 읽는 것까지 확인했어요.
- `--model 'claude-opus-5[1m]'` 처럼 대괄호 붙은 ID 도 그대로 먹혀요.
- 실행한 cwd 에서 세션이 떠요. 워크트리에서 이어가야 하면 `cd` 를 같이 묶어요.

출력에 잡 id 가 나와요. 이걸 기록해요.

### 보고하고 끝낸다

**결과를 기다리지 않아요.** 띄웠으면 이 세션의 일은 끝이에요. 마스터에게 세 줄로 알려요.

- 문서 경로
- 잡 id 와 확인 명령 (`claude logs {id}`, `claude attach {id}`)
- 문서의 "확인 필요" 에 남긴 것이 있으면 그 목록 — 마스터가 지금 답해줄 수 있는 것일 수 있어요

## 루프

새 세션도 언젠가 컨텍스트가 차요. 그때 그 세션이 다시 이 skill 을 호출해요. 문서를 새로 쓰되 이렇게 이어요.

- TODO 에서 끝낸 항목은 `[x]` 로 바꾸고 지우지 않아요.
- "세션" 절에 앞선 문서 경로와 직전 세션 ID 를 남겨요. 사슬이 끊기지 않아야 거슬러 올라갈 수 있어요.
- 새로 조사한 것은 "조사 결과" 에 누적해요. 앞 문서에 있던 근거를 요약해서 줄이지 않아요 — 요약할 때마다 근거가 닳아요.

## 흔한 실패

- **문서를 쓰지 않고 프롬프트에 요약해서 넘기는 것.** 프롬프트는 다음 세션이 갱신할 수 없어요. 문서라야 다음 세션이 이어 쓰고 다음다음 세션에 넘겨요.
- **"코드 보면 안다" 며 조사 결과를 생략하는 것.** 다음 세션은 같은 조사를 처음부터 반복하고, 컨텍스트를 조사에 다 써요.
- **버린 대안을 안 적는 것.** 다음 세션이 버린 안을 다시 채택해서 되돌아와요.
- **`--print` 를 붙이는 것.** 세션이 아예 안 떠요.
- **결과를 기다리는 것.** 백그라운드로 띄우는 이유가 없어져요.
- **완수조건 없이 넘기는 것.** 다음 세션이 범위를 넓히거나 절반에서 멈춰요.
